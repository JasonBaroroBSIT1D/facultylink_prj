About FacultyLink

FacultyLink is a faculty self-assessment and academic rank simulation platform designed to align with applicable DBM–CHED evaluation guidelines. It helps faculty organize evidence, understand KRA progress, and preview rank readiness in a structured, transparent way.

FacultyLink provides self-assessment estimates and academic rank simulations for reference only. Results do not constitute official faculty performance evaluations, promotion approvals, or rank reclassification decisions. Use of the CHED building imagery is for visual context only and does not imply CHED endorsement of FacultyLink.
